# 0.8.7：gallery-registry 的库名归宿主（`configureGalleryRegistry({ dbName })`）

> created 20261021 by Claude Fable 5.1 · as-of 0.8.7 · 道 6 F-58 §8 第 2 件（家族根 `ai-docs/20261021-idb-localstorage-inventory-and-split-proposal.md`；user 2026-10-21「gallery-registry 库名改宿主传 可以」）。patch。

registry 是宿主**这台设备的记事本**（store ADR-0024：per-gallery、device-local、永不同步），库名却在包里写死成 WeebPaint 的 GUID `weebpaint-bd6cece69075d759.gallery-registry`——别的宿主（WXHW / MoonSinger / KudsRocket）一用就把自己的图库登记写进 WeebPaint 名下的库。

- `configureGalleryRegistry({ dbName })`：第一次开库之前配（形状同 `configureDeviceKv`）。
- 没配 = 退回老字面量（既有 WeebPaint 用户零迁移）+ `diag` 记一次「宿主没配」。
- 开过库再配 = 编程错误 → 抛（晚配等于两个库各一半）。
- `galleryRegistryDbName()` 给测试 / 诊断看实际用的名。

WeebPaint 侧（道 2 收包时）：boot 早期一行配置（用它自己的 GUID 名 = 今天的字面量，零迁移）+ CLAUDE.md 持久层白名单表。别的宿主配自己 `<app>-<guid>.gallery-registry`。
