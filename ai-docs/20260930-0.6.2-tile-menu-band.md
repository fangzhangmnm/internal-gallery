# 0.6.2：卡片 ⋯ 菜单出卡片、进菜单 band
> created 2026-09-30 by Claude Fable 5.1 · as-of 0.6.2

## 起因

user 2026-09-30 iPhone 真机截图（WXHW 书库）：卡片 ⋯ 菜单弹出来，下半截被下一排卡片盖住。原话「z order系统的解决一下，看一下weebpaint怎么做的」「所以已经有ui深模块窄接口了吗」。

## 根因

菜单是卡片里的 `position: absolute; z-index: 5`。卡片 `.gallery-tile:hover { transform: translateY(-1px) }`；iOS 上点一下 `:hover` 会粘住 → `transform` 让卡片自成层叠上下文 → 菜单的 z 只在卡片内部算，卡片本身 z 是 auto、按 DOM 顺序画 → 后面的卡片盖上来。无头 Chromium 没有粘 hover，量不出。

不是 iOS 特有：任何 `transform / filter / opacity / contain / will-change` 出现在卡片或它与 `.gallery-full` 之间的祖先上，都会再犯。所以不是「把 hover 的 transform 删掉」能了结的事。

## WeebPaint 怎么做

`anchored-popup.ts`（`positionPopup`）+ `popup-menu.ts`：菜单节点挂 body、`position: fixed`、坐标按锚按钮算、z 走 `--z-*` band 表；外点关 / Escape / 栈 / resize 重定位内建。这两个已经在 `@internal/workbench-elements`（0.1.0 抽出），`popup-menu.ts` 头注释点名「图库三 popup」该走它的收养 adapter（`openAdoptedPopup`）。图库包一直没接——本轮接上。

## 做法

| 层 | 做什么 |
|---|---|
| DOM | 四处菜单（文件 / 夹 / 图片 / 搁置区）各自包一层 `<Teleport :to="menuMount">`，`menuMount` = `createGallery(el)` 的挂载点。节点由 Vue 搬，Vue 自己的 patch 不会乱（收养 adapter 的 `mountToBody` 会 `appendChild`，v-for 里的节点不能让别人搬） |
| 生命周期 | `toggleAdoptedPopup(popup, { anchor: ⋯钮, align: "right", band: "css", position: "anchor" })`：定位（`positionPopup`，钳视口）、外点关、Escape、上下键、栈、resize 重定位、**外部滚动收**（workbench-elements 0.1.1 新加：菜单 fixed 之后滚网格它会漂） |
| z | `gallery.css` `.gallery-tile-menu-popup { position: fixed; z-index: var(--z-menu, 400) }`（band 归宿主 `:root`；宿主没定义时兜底 400，别再像 2026-09-10 那样掉成 auto） |
| 契约 | `VueRuntime.Teleport` 必填（宿主 gallery-host 从 vue 模块多递一个）；peer `@internal/workbench-elements >=0.1.1` |

退役：`menuUp` / `.up`（贴屏幕下缘往上翻）——`positionPopup` 的 `clampViewport` 把菜单夹进视口底，等价。`openMenu` 只剩「哪个开着」的影子状态，关闭统一走 `closeMenu()`（handle.close → onClose 清）。

## 验证

- 包：tsc / 170 测试 / api 户口。
- WXHW ui-audit 新探针：菜单节点在 `#galleryMount` 直系（不在卡片里）、`position: fixed`、菜单矩形内任一点 `elementFromPoint` 命中菜单而不是卡片、网格滚动后菜单收起。
- iOS 真机归 user。

## 0.6.3 追加（同日）：user 真机「gallery的删除好像有问题，删不了」

无头 iPhone 12 触屏上下文复现「⋯ → 送到回收站 → 确认 → 进回收站」整链正常，所以是 iOS 特有。两个只在 iOS 出现、且都是 0.6.2 / 0.1.1 引进的嫌疑，各用结构消掉：

| 嫌疑 | 机制 | 修 |
|---|---|---|
| 粘住的 hover 解除 | iOS 没有 hover，tap 把 `:hover` 粘在卡片上；菜单出了卡片后，手指点菜单项 = 离开卡片 → hover 解除 → `transform` 变化 → Safari 把这一下当 mouseover、吞掉 click（经典「iOS 要点两下」）。0.6.1 以前菜单在卡片里，点菜单项不离开卡片 | `gallery.css` 所有会动版面 / 透明度的 hover 规则进 `@media (hover: hover)`，卡片 hover 不再 transform（只剩阴影） |
| 幽灵 scroll | workbench-elements 0.1.1「菜单外滚动 = 关」；iOS 的 tap 有时伴随 `scroll` 事件 → click 到达前菜单已收 | workbench-elements 0.1.2：只在锚真的移了位（> 0.5px）才关 |

iOS 真机仍归 user；若还删不了，需要知道是「菜单点不开 / 点菜单项没反应 / 确认了没反应 / toast 说了什么」哪一种。
