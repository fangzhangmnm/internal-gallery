# 0.8.5：「删除」改调 store 的 `file.trash()`（跟 store 2.1.2 的改名）

> created 20261018 by Claude Opus 5.5 · as-of 0.8.5 · user 2026-10-17 深夜（store 会话）「改trash，但是还是这个major，甚至不bump minor，因为只是让词对准了它应该有的语义罢了，属于bugfix」→ store 2.1.2 把 `RawFile.delete()` 改叫 `trash()`（无别名）；10-18「别的项目也接一下」。patch。

- `VerbFile.delete()` → `trash()`；图库「删除」（文档 / 图片）调 `file.trash()`，诚实读 `TrashOutcome`（cancelled / noop / 只删了本地 照旧不报「已删除」）。界面文案不动（用户看到的仍是「删除」）。
- `peerDependencies["@internal/store"]` = `>=2.1.2`（老 store 没有 `trash()`）。宿主**收 gallery 0.8.5 必须同时收 store ≥ 2.1.2**；还钉 store 0.18.x 的宿主留在 gallery 0.8.4。
- 开发用的 store 换成 2.1.2。176 测试。

## 行为差异

无（只是换了调用的名字）。
