# 0.8.0：卡片的动作钮（ui.tileAction）+ 卡片的「事实」（policy.facts）

> created 20261016 by Claude Fable 5.1 · as-of 0.8.0 · minor（user 2026-10-16「图库包批了」）。起因 = MoonSinger W-38 定稿：歌库封面上要一粒 ▶ 直接放存进歌里的 mp3（user「gallery可以试听mp3不用开app」），
> 宿主第一版绕了三处（往覆盖槽塞钮 + CSS 给它 `pointer-events: auto` + capture 阶段拦卡片点击 + MutationObserver 扫卡片自己尾读总目录）。本版把这两样收成包的正式接口；包仍 content-blind。

## 加了什么（都是加法，老宿主不改一行照跑）

```ts
// GalleryScreenDeps.ui
tileOverlayHtml?: (name: string, info?: TileInfo, facts?: unknown) => string | undefined;   // 多一个 facts
tileAction?: (name: string, info: TileInfo, facts: unknown) => TileAction | null;           // 新
export interface TileAction { icon: string; title: string; state?: "ready" | "none" | "unknown" }
// GalleryDocHost
tileAction?(item: GItem, facts: unknown): void | Promise<void>;                             // 新：点了钮（不打开那份）
// CreateGalleryDeps.policy
facts?: { kinds: readonly string[]; fetch: (identifier: string, source: "local" | "cloud") => Promise<unknown>; store?: ThumbStore; dbName?: string; galleryId?: () => string };
// Gallery
facts: FactsCache | null;   // invalidate(identifier) / clear()
// 门牌
export { createFactsCache, factsKeyFor, type FactsCache, type FactsSource, type CachedFacts } from "./core/facts/facts-cache.ts";
```

- **事实**（`src/core/facts/facts-cache.ts`）：和缩略图同一套——按身份 + 字节版本（token = lastModified / size）缓存在宿主给的 IDB（`dbName`，object store `gallery-facts`，全删可再生）；fetch 返 null = 确定没有（照样进缓存），抛 = 未知（不写缓存、退旧值）；加密件不取（尾读到的是密文）；并发限 3；`invalidate` 清掉重取。屏幕里是响应式 Map：事实到了 → `fileTiles` 重算 → 覆盖层 / 钮跟着。
- **动作钮**（gallery.css `.gallery-tile-action-slot` / `.gallery-tile-action`）：槽和缩略图同一块几何（`top: 0` + `aspect-ratio: var(--tile-aspect)`），槽不吃指针事件、钮吃；`@click.stop` 不开卡；`state: unknown` 淡、`none` / null 不画；图标走宿主的 `ui.iconHtml`；搁置区卡、列表布局不画。

## 消费方

MoonSinger v0.12.22 第一个收：`facts.fetch` = 尾读 `.moonsinger/manifest.json` 回 `{ final: { rev, secs } } | null`；`tileAction` = 定稿了才有 ▶，点了抓 `.moonsinger/final.mp3` 放。宿主那三处绕路删掉。
别家能用同一个口：WXHW 书架的字数 / 读到哪、JRB 的进度角标、以后 MoonSinger W-30 的自动预览图——都是「不开文件就想知道的一点事实」。

## 没做

- 事实的 IDB 和缩略图的是两个 DB（宿主各给一个 dbName）；合成一个要动 IDB 版本（onupgradeneeded 加 store），存量设备要迁，先不碰。
- 钮只有一粒；要几粒再说。
