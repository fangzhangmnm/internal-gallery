# 0.8.3：「云端刚没了」那一行只剩「处理…」；徽章说明改成词汇表的话

> created 20261017 by Claude Fable 5.1 · as-of 0.8.3

起因：store 0.18.5 审计（KudsRocket user 2026-10-17「云端没有的情况点处理没有给选项，然后一直卡着待处理」→ 库修了 `resolve()` 对干净副本的处理；审计顺手看图库同一行）。

- `pendingGone`（云端那份没了、这台还留着一份干净的副本、24 h 宽限期内）那一行的卡片菜单以前是「处理…」+「送到回收站」。「送到回收站」= 库的双向删除，和 KudsRocket 2026-10-14 00:54 丢手动存档是同一个坑（user 2026-10-16「冲突的时候不要放删除按钮」）。现在只剩「处理…」：这份不要了 = 面里选「云端覆盖本地」（store 0.18.5 起干净副本也走这张面，0.18.6 起云端那份回来了就不动、报 cloud-reappeared）。
- 徽章说明 `gv.badge.pendingGone`（zh / en / ja）以前写「可「重新上传」推回云端，或「删除」」——0.8.1 删掉那两个方向动词之后这句一直没改。现在说的是面里的三个词。
- `ghost`（云端没了 ∧ 这台有没传的改动）那一行**没动**：它还是「重命名留存」+「丢弃（送回收站）」两个按钮、不走「处理…」。「丢弃」也是方向动词、在面外——按 2026-10-16 的词汇表标准同样不合法，但换成「处理…」会少掉「重命名留存」（两份都留）这条路，要 user 定，这里只记不改。
- 代码零逻辑变化；配 store ≥ 0.18.5 才有「处理…」弹面（0.18.4 下按它仍回「没有要处理的」）。
