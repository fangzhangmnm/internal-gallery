# 0.8.4：模板构建时编好（宿主开 CSP 也能开书库）
> created 20261017 by Claude Opus 5.5 · as-of 0.8.4

**为什么**：WXHW 2026-10-17 给页面加了 CSP（user「csp是什么？甲一起上」——跟「在这台设备上记住密码」一起上，挡注入脚本偷口令）。策略不放行 eval，而 Vue 完整版在运行时编译模板要 `new Function` → 书库屏 `EvalError`、打不开（boot smoke 红）。

**做法**：三张模板原样搬进 `src/ui/templates.ts`；构建时 `scripts/compile-templates.mjs` 用 `@vue/compiler-dom` 3.5.35 prod 构建（`mode: "function"`、`prefixIdentifiers`、`hoistStatic`、`cacheHandlers`、去注释）编成三个 `xxxRender(Vue)` 工厂，helper 从宿主递进来的 Vue 里解构——包仍然不 import vue。

**行为差异**（宿主升级逐条过）：
1. 宿主递**整个 Vue 模块** → 用编好的 render，运行时不编译模板。渲染结果应与运行时编译相同（同版本编译器、同选项；去注释 = prod 运行时编译的默认）。WXHW boot smoke 37 项 + 书库探针在 CSP 下零拦截。
2. 宿主只递老的 10 个成员 → 和 0.8.3 完全一样（运行时编译），黑匣子多一条 `[gallery] host passed a partial Vue runtime…`。
3. 含 0.8.3 的全部改动（pendingGone 行只剩「处理…」）——**要 store ≥ 0.18.5 才有弹面**。

**升 Vue 时**：改 `scripts/compile-templates.mjs` 的 `VUE_VERSION` + devDep 版本 → `npm run build` 重生 → 发版；各 app 的 vendor Vue 同步换。
