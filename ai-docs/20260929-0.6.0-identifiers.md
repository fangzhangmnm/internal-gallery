# 0.6.0：改吃 store.identifiers——图库不再自己切名字
> created 20260929 · by Claude Fable 5.1 · as-of 0.6.0

设计与用词的出处都在 store 仓：`20260813 internal-store/ai-docs/20260929-proposal-doc-types.md`（user 2026-09-29 批；用词 identifier / folder / stem / suffix / kind 逐词定）。这份只记 gallery 这一刀落地的形状。

## 变了什么

| 0.5.0 | 0.6.0 | 说明 |
|---|---|---|
| `GItem { name（裸名）… }` | `GItem { identifier, stem, kind, … }` | 身份永远是全名；主干只给人看；种类是宿主在 store 报的标签 |
| `policy.naming`（bare / full / display）、`deps.naming` | 删 | 切身份、拼身份全走 `store.identifiers`（store ≥ 0.16.1） |
| `policy.isDoc` | 删 | 哪些是文档由 store 的 docKinds 表说 |
| `deps.isZipDoc` | 删 | 动词只用 RawFile 面；`getEncryptedBlob` store 0.16.0 起在 RawFile 上（加密 txt 也能复制了） |
| `deps.hasThumb`、`policy.thumbs.has(fullName)` | `policy.thumbs.kinds: string[]` | 哪几个种类有缩略图 |
| `VerbHost.activeName()` | `activeIdentifier()` | |
| `VerbDoc.setName(name)` | `setIdentifier(identifier)` | |
| `VerbStore.file(name, {isZip, mode})`、`files.nameOccupied` | `file(identifier, {mode})`、`files.occupied` | 跟 store 0.16.0 |
| `GallerySnapshot.path`、`CloudImageItem.path / name` | `folder`、`identifier / label` | |
| `AsideItem.kind: AsideKind`、`.name` | `.box: AsideKind`、`.identifier` + `.stem` + `.kind: string \| null` | kind 让给文档种类；箱子叫 box |
| `copyTargetName(name, taken)`、`uniqueBareName(stem, occupied, naming)` | `copyTargetName(identifier, taken, ids)`、`uniqueIdentifier(identifier, occupied, ids)` | 主干后接一段、后缀不动（修了「书.webxiaoheiwu.zip 副本」） |
| `imageTwinBareName(folder, basename)` | `imageTwinIdentifier(folder, basename, docSuffix)` | 图片转生成 docKinds 表里**第一种**文档 |
| `storeUIFor({ naming })` | `storeUIFor({ stemOf })` | 冲突面上显示主干 |
| `changePasswordFlow` 端口 `naming` / `invalidateThumb(bareName)` | 删 / `invalidateThumb(identifier)` | |
| `library-backup` 快照端口 `path` | `folder` / `identifier` | 跟 store 的 FolderSnapshot |

宿主收货时的编译错误就是迁移清单。WXHW 的接法见 `20260516 WebXiaoHeiWu/src/gallery-host.ts`（v2.1.23）。

## 没变的

界面模板、class 名、文案 key、回收站 / 备份箱视图、覆盖层槽 `ui.tileOverlayHtml`、占位槽 `ui.tilePlaceholderHtml`（都收身份）。

## 验证

包测试 170 项全过（tests 按新形状改写；删了三条只测裸名边界的用例）。界面这一层靠 WXHW 的审计和端到端验。
