> created 20261026 by Claude Fable 5.1 · as-of 0.8.8 · user 2026-10-26「可见钮 + 顶部列表」（家族根会话；起因 = user 同日「处理的东西应该图库上多一个按钮图示。现在的情况是那些要处理的东西只有非常小的云图标提示，然后用户完全找不到在哪里处理（在...里面）……你一开始说批量处理我以为的是给你一个列表你当时就立刻点」）。
> 复盘：家族根 `ai-docs/20261026-cloud-conflict-ux-postmortem.md`（周账 F-98）§4 第 3 条、§5 B。配套店库 2.2.1（假冲突根因）。

## 1. 改了什么

1. **「处理…」不包在宿主 busy 里**（`verbs.resolve`）：它中途要弹面问人，宿主的 busy 要是一层模态遮罩，面就被挡死——CatsUp 2026-10-25 iPad 截图「没处理成：…sheet "choice" opened while busy overlay is active (would deadlock)…」（CatsUp v0.14.8 用闸门面板绕过；WXHW 同病 = 周账 F-91 的根）。推 / 拉的忙碌提示店库自己有 busy 键（`sync.pushing` / `file.pulling` / `cloud.checking`），宿主按键路由。防双击：同一份在飞时再点一次忽略。
2. **卡片上可见的「处理…」钮**：`GalleryTile.attention`（登录态 ∧ float / dirtyBoth / conflictBoth / ghost / pendingGone = store `resolve()` 真能做事的集合；localOnly 干净从没传过的不算——`resolve()` 对它回 clean；newerOnCloud 不算——打开就自动快进）。宿主没给 `ui.tileAction` 的卡片，库自己在 0.8.0 的动作钮槽位放一粒琥珀的带字钮「处理…」（`TileAction.verb = "resolve"` → `verbs.resolve`）；宿主给了钮的照旧用宿主的。列表布局照旧不画槽（⋯ 菜单里仍有「处理…」）。
3. **顶部横幅**：当前夹有要处理的 → 面包屑下一条「有 N 份没同步好，要你处理 → [看列表]」；点了只看那几张（文件夹 / 图片 / 其他文件暂时不显示），每张右下角一粒「处理…」，点了当场弹店库的面。都处理完 → 自动回全部。`GalleryHandle.setAttentionOnly(on)` / `getAttentionCount()` 给宿主（CatsUp 登录落地后发现有没传上去的 → 直接开图库进这个视图，代替 10-21 那个「有 N 个模型只在这台设备上，现在传吗」的是 / 否框）。
4. 文案：`gal.attention.banner / showing / list / all`（zh / en / ja）；`gv.badge.ghost` 不再提「丢弃」（0.8.6 就没了，文案漏改）。

## 2. 和 10-21「只剩处理…这条线冻结」的关系

冻结的是「面外方向动词拿掉」这个设计（user「不一定好，记账有空好好讨论」）。本版**没加也没退任何方向动词**，只是把已有的唯一动作「处理…」从 ⋯ 菜单里搬到看得见的地方、加了个数。user 2026-10-26 四问之一「图库入口 → 可见钮 + 顶部列表」= 对这一步的明确同意；方向动词本身的讨论（F-70）照旧挂着。

## 3. 行为差异（宿主升级逐条过）

| | 0.8.7 | 0.8.8 |
|---|---|---|
| 「处理…」 | `host.busy(...)` 包着 `file.resolve()` | 不包；宿主若靠 busy 当唯一进度提示，推 / 拉期间仍有店库的 busy 键 |
| 要处理的卡片 | 只有 12 px 徽章 + ⋯ 菜单 | 多一粒琥珀「处理…」钮（宿主有自己的 tileAction 时不覆盖） |
| 顶部 | 无 | 有要处理的才出现一条横幅；点「看列表」= 筛选 |
| `GalleryHandle` | — | 多 `setAttentionOnly` / `getAttentionCount` |
| `GalleryTile` | — | 多 `attention: boolean` |

CSS 新类：`.gallery-tile-action.verb-resolve`、`.gallery-tile-action-ico / -label`、`.gallery-tile.attention`、`.gallery-attention-bar / -text / -toggle`（都在包的 `gallery.css`；宿主拷新的 css）。
