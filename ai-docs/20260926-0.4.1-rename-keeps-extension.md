# 0.4.1 — 改名只编辑主干，原扩展名自动保留（身份 = 全名的宿主）
> created 20260926 · by Claude Fable 5.1 · as-of 0.4.1

## 起因（WXHW 真机，2026-09-26）
user：「重命名的时候不应该包含扩展名(.webxiaoheiwu.zip)」→「修」。书库卡片「改名」= `verbs.rename`：默认值 `candidate = item.name`，而 WXHW 身份 = 全名（`naming` 恒等、只给 `display` 去扩展名）→ 框里出现 `X.webxiaoheiwu.zip`；且结果原样 `tryMove(naming.full(输入))`——用户把扩展名删掉再确认 = 文件真改成无扩展名 → 宿主 `isDocName` 不认 → 从书库消失（字节在，找不到）。

## 改动
- `verbs.rename`：给了 `naming.display` 的宿主，输入框默认值 = `display(name)`；确认后把原名被 display 去掉的那截后缀自动补回（用户自己打了同样后缀不重复）；「未变」判定与 toast 都按主干说。撞名 / 失败重问时默认值也是主干。
- 裸名↔全名有边界的宿主（WeebPaint `X`↔`X.ora`，不给 display）行为不变。
- 测试 `verbs.test.mjs` +4（WXHW 书 / txt / 不重复后缀 / 撞名重问 / WeebPaint 不变）。157 绿。

## 不变
公共面零变化（`NameBoundary` 三字段不动，只是 `display` 多承担「改名编辑面」这一语义——它本来的注释就是「身份=全名的 app 用它去扩展名」）。
