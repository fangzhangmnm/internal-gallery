# 0.8.6：ghost 行也只剩「处理…」；回收站 / 备份箱视图有了「清空…」

> created 20261021 by Claude Fable 5.1 · as-of 0.8.6 · user 2026-10-21「gallery 做」（周账道 1 列的两条）。patch。

## 1. ghost 行（云端没了 ∧ 这台有没传的改动）

0.8.3 把「云端刚没了、这台干净」那一行改成只剩「处理…」，ghost 行**没动**：还是「重命名留存」+「丢弃（送回收站）」。「丢弃」是面外的方向动词（= 替人选了「云端覆盖本地」），和 user 2026-10-16「冲突只在库的面里三选一」「app 不替人回答」相撞。

现在：「**处理…**」= store `file.resolve()`（库弹面：本地覆盖云端 = 把这份推上去 / 云端覆盖本地 = 这份进回收站 / 取消；store 0.18.2 起面会按 `cloudState` 说「云端没有这份」）+「**重命名留存**」（不是同步动词，是改身份另存，留着）。`gal.discardToTrash` 文案键删了。

## 2. 「清空回收站… / 清空备份箱…」

store 的 `files.emptyTrash / emptyBackup` 和本包的 `emptyAside` 动词早就有（含确认框、部分失败必说），但图库屏幕从没给过入口（store README 一直写着「暂无 gallery UI，控制台 / 以后面板调」）。现在回收站 / 备份箱视图不空时，顶上一条 `.gallery-breadcrumb.gallery-aside-bar` 里一粒 `.danger` 钮，点了走 `emptyAside(view)`（scope = both）。复用面包屑的容器 / 按钮样式，宿主零 CSS；想单独调样式按这两个 class。

## 行为差异

- 开了图库的宿主：ghost 行菜单少了「丢弃」、多了「处理…」；搁置区多一粒钮。别的零变化。
- 文案键：删 `gal.discardToTrash`；加 `gal.emptyTrashBtn` / `gal.emptyBackupBtn`（zh / en / ja）。
