# 0.7.1：冲突面主按钮改成「云端覆盖本地」

> created 20261016 by Claude Fable 5.1 · as-of 0.7.1 · patch。user 2026-10-16「冲突面文案用『云端覆盖本地 / 本地覆盖云端』」「一切对齐」「默认云端才是 authority」。

## 行为差异（和 0.7.0 比）

保存时撞上云端不一样的那张面（`src/ui/store-ui.ts` `resolveConflict`，occasion = push）：三个按钮不变（云端覆盖本地 / 本地覆盖云端 / 取消），**主按钮从「本地覆盖云端」换成「云端覆盖本地」**，顺序也换成云端在前。打开时那张面（打开本地 / 云端覆盖本地）不变。

为什么：WXHW 2026-10-16 真机——挂机醒来弹面，主按钮是「本地覆盖云端」，半梦半醒顺手一点，云端的新改动就进了备份箱（能找回，但等于丢）。云端那边是别的设备刚存的，默认该偏它。

文案本身没动（`cf.act.*` 三种语言照旧）。KudsRocket（不用本包）同日自己改成同样的三个词 + 云端主按钮。
